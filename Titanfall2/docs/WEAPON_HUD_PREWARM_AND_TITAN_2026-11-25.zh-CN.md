# Sandbox 挂载：武器显示、资源预热与泰坦行为

本批接续 `WEAPON_FIDELITY_2026-11-25.zh-CN.md`，面向官方 s&box 的 Sandbox 挂载内容。所有生产修改均位于 Titanfall2 addon，不依赖自改引擎。构建与运行证据分开记录；下述行为不代表完整复刻原游戏。

## 第一人称与武器显示

快速转头的一个可复现错误来自相机放置阶段：旧代码将上一阶段缓存的世界骨骼与更新后的 SceneModel 根变换配对。现在从父空间骨骼链计算 CAMERA_BASE，避免混用两个阶段的根变换；原有 sway 参数保留。原生 split-root 对照中的额外旋转从约 90 度降为 0 度。普通快速转头采样未自然复现用户截图级抽动，因此真实游戏的最终主观体验仍需观察。

新增随散布变化的腰射准星，冲刺、换弹、完整镜面瞄准时隐藏；普通 ADS 暂用中心细点。完整 HCOG/AOG RUI 瞄具仍未实现。

枪身弹药显示读取原 MDL53 的 RUI 单骨骼平面四边形与 WeaponData 的 ammo 绑定，显示真实弹匣状态。没有支持面片的枪不凭空生成屏幕。原始骨骼动画驱动屏幕位置，采用相同的父空间骨骼读取方式。原生 WorldPanel 的坐标基与朝枪体内的面法线分别适配。样式资源 `Assets/gameplay/weaponammodisplay.panel.cs.scss` 必须随 DLL 部署。

用户指出数字位置仍偏后，进一步检查原版 `client.dll`、`engine.dll`、编译 `ui(11).dll` 与 RPAK，发现初版面片解析错误：32 字节 face 实际为 U[4] 和 V[4]，原版 `engine!0x1800FF440` 通过 map 指向的三个顶点求完整 UV 仿射平面。旧解析把前四个 float 当作两个 UV 起止点，误把约半高的可视窗口扩成整个画布。修正后区分完整 UV 画布与原始 face 窗口，并在窗口中裁剪完整 UI 内容。R201 完整 UV 高度约 0.820265、CAR 约 0.593118，而各自可视窗口约为 V [0,0.52] 与 [0,0.51]。CAR 原始数值回归与非法 map 回归 2/2 通过。

两块 lower RUI 的原始画布均为 256×256、字体样式 ID 9（MetronicProRegularFont）、字号参数 120。编译界面使用 `%i`，不能补零，也不能把 54/74 字节码终点当作字号。R201 的文字锚点是 (69.12,56.32)，CAR 是 (128,64)，均使用文字框中心 pivot；字宽、字距、基线和 glyph 来自原字体资源。通用居中 Roboto、经验 70px 字号与额外剩余条已移除。证据位于 `artifacts/retail-rui-layout-20261125/`。

此前原生报告虽通过弹数与角点检查，用户截图仍暴露 R201 的“24”上下倒置；当时将 CAR 的“30”判为方向正常也不可靠，因为这两个数字近似上下对称。已撤回该轮方向验收。根因是官方 `core/shaders/ui_cssbox_batched.shader` 与 `ui/vertex.hlsl` 在乘 WorldMat 前还会执行像素 Y 反射，而旧适配只反演了 WorldPanel 的旋转矩阵。现在将这一层反射纳入坐标基与角点计算，保留原字体像素、原 UV 和原文字锚点；不做单枪硬编码翻转。最终 `retail-async/` 验证让两把枪都显示非对称的“24”，两位执行代理分别查看新截图，确认字序、上下方向和裁剪正确。旧 `native/`、`retail-native/` 图片均不作为最终方向证据。

## 生成与装备预热

生成、拾取及应用配件时收集当前武器的声音事件、枪口、抛壳、曳光、发射物与命中依赖。声音事件展开所有实际采样变体，使用与真实播放相同的 exact/loop 缓存身份。后台执行文件读取、Miles 解码与目标 PCF 解析；主线程按帧接纳原生资源创建，每帧预算为 2 毫秒，但单个不可拆分原生操作可能超过该值。

预热不在用户场景播放假声音或假粒子。粒子原生组件在独立未渲染场景创建后销毁，实际效果使用同一资源缓存。目标图及子图的随机贴图序列逐一加入分帧队列，使用真实工厂相同的纹理/帧率/序列身份，避免只预热一次随机采样后误报就绪。请求去重，不保留武器或游戏场景引用，挂载缓存释放与卸载使旧请求失效。`PrewarmStatus` 与 `PrewarmErrors` 提供完成、失败、声音/粒子/模型数量与耗时。

这些操作移动读取、解码和部分原生创建成本，不能认证首次绘制时的 GPU pipeline 已编译，也不能保证生成后立即开枪没有冷加载。`GpuPipelineWarmed` 明确保留为 false。

## 泰坦、护盾与 NPC

- Ion 使用前向解析拦截体积，宿主处理命中扫描与真实发射物，消耗已捕获弹体并在释放时改为护盾拥有者归属。仅吸收束流不会变成返还弹药。当前仍为 AI 风格窗口与再次按键释放，完整共用能量与持续按住输入尚未实现。
- Legion 枪盾有独立 2500 点耐久与 6 秒时长，破盾立即失效；爆炸压力单独结算，不会被当作弹药捕获。前向几何仍为显式适配，未宣称原生形状完全相同。
- 普通泰坦宿主生命周期为 Normal、Doomed、Ejecting、Dead；采用零售多人 2500 点 Doomed 储备。普通致命溢出不穿透新储备。弹射先检查出口并脱离座位，恢复控制后施加速度，再处理机体自毁。
- 伤害统计记录引擎扣血前的真实血量。引擎 Health 在零处截断，不能通过“扣血后血量 + 伤害”反推；宿主核心计分只使用已验证交付且真实扣除的数值，兼容嵌套伤害和新储备池。
- NPC 动画保留零售 aim 网格、pose keys、autolayers、事件与权重。已实现可验证的静态 aim 图层；未知标志仍保留数据，不擅自执行。
- Mortar Titan 使用移动、等待、部署、射击、恢复状态，读取原动作事件的 7 个发射时机与枪口骨骼。导弹追踪目标实体加原脚本随机偏移，并按距离更新转向速度。缺少原版导演布点时，Sandbox 生成位置作为炮位；原生导引求解器仍为适配。

## 最终预热与部署

字体、atlas 解码、数字栅格化与指定 UI 布局查找已合入同一个后台 worker。HUD 的布局、字体及 glyph getter 只读取已发布缓存；未就绪时等待并重试，不在绘制中执行同步资源读取。冷缓存 getter 两次查询合计约 0.6073 毫秒。

`artifacts/weapon-prewarm-20261125/async-report.json` 为最终原生结果：R201 110/110 项、零失败，60 个声音、5 个粒子图、12 个贴图序列和 10 个数字纹理完成。准备总计约 4.531 秒，主线程累计约 497.571 毫秒，单步骤最大约 217.599 毫秒、类别 Model。旧 UI/font 同步版本的约 4741.593 毫秒步骤不作为最终实现。预热完成后的真实首枪及后续 60 帧，新增声音加载、解码、sprite cache key 和字体 glyph 均为 0；首枪调用约 14.0471 毫秒。仍观察到约 224.638 毫秒的渲染/flush 步骤，因此不宣称生成或首次绘制无卡顿。
