# Assets/ — Shaders & UI Stylesheets

Contains s&box shaders/HLSL includes (`Assets/shaders/`) and UI stylesheets (`Assets/gameplay/`).

## Layout
- `Assets/shaders/` — 31 `.shader` files + 18 `.hlsl` shared includes, all prefixed `titanfall2_*`:
  - World & props: `titanfall2_world_lightmapped.shader`, `titanfall2_default.shader`, `titanfall2_static_scene_cs.shader`, `titanfall2_static_scene_vertex.hlsl`, `titanfall2_gpu_material_table.hlsl`.
  - Lighting & probes: `titanfall2_local_lights.hlsl`, `titanfall2_probe_data.hlsl`, `titanfall2_probe_inputs.hlsl`, `titanfall2_probe_lighting.hlsl`, `titanfall2_height_fog.hlsl`.
  - Surface & transparency: `titanfall2_surface.hlsl`, `titanfall2_normals.hlsl`, `titanfall2_emission.hlsl`, `titanfall2_detail.hlsl`, `titanfall2_vmt_layers.hlsl`, `titanfall2_alpha/additive/cutout/translucent/distortion/hologram/godray/water/vista*.shader`.
  - Decals & particles: `titanfall2_decal*.shader`, `titanfall2_particle_ramp/refraction/rope.shader`.
  - Post-processing: `titanfall2_tonemapping.shader`, `titanfall2_bloom_cs.shader`, `titanfall2_exposure_cs.shader`, `titanfall2_color_correction.shader`, `titanfall2_color_lut_blend_cs.shader`.
- `Assets/gameplay/weapons/ui/weaponammodisplay.panel.cs.scss` — Stylesheet for `Titanfall2WeaponAmmoDisplay` (`Code/Gameplay/Weapons/Ui/WeaponAmmoDisplay.Panel.cs`).
- `Assets/navigation/titanfall2_rooftop_{jump,climb}.navlink` — Typed NPC roof connections, consumed by `Titanfall2TraversalLink` and `Titanfall2NpcNavigationLayer`. Keep these assets available when packaging the mount; missing types must not degrade to untyped links.

## Invariants & Pitfalls
- **`PanelComponent` SCSS path coupling**: s&box resolves `PanelComponent` stylesheets by mirroring `Code/` relative path into `Assets/` (`ClassFileLocationAttribute + ".scss"`). If you ever move or rename `WeaponAmmoDisplay.Panel.cs` (or add a new `PanelComponent`), you MUST mirror its exact path under `Assets/` in lowercase.
- **Shader compilation artifacts**: `.shader_c` files are compiled shader binaries generated by s&box; do not hand-edit `.shader_c`.
- **Keep `titanfall2_` prefix**: All mount shaders use the `titanfall2_` namespace prefix to avoid collisions with host/sandbox shaders.
- **Prop normal-frame variant**: `F_T2_FAST_NORMAL` on default/cutout removes the determinant magnitude before tangent normalization, retaining its sign and scaled degeneracy threshold. Keep the reference variant for native A/B checks, including mirrored UVs. Do not change alpha coverage or geometry to make a shader benchmark faster.
